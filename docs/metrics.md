# Product Metrics

| Metric | Definition | Purpose |
|---|---|---|
| Checkout completion rate | Completed orders / checkout starts | Primary outcome |
| Bag-to-checkout rate | Checkout starts / bag views | Entry into checkout |
| Address-to-payment progression | Payment step views / address step views | Step friction |
| Coupon success rate | Successful coupon applications / coupon attempts | Offer clarity |
| Payment failure rate | Failed payment attempts / payment attempts | Guardrail |
| Cancellation rate | Cancelled orders / completed orders | Guardrail |

Metrics require consistent event definitions, deduplication and a clearly specified time window. Correlation does not prove that a UI change caused a change in business outcomes.
